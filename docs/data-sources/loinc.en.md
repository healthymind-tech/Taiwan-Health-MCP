# LOINC Data Source

## International standard
- **Authority**: the Regenstrief Institute
- **Version**: the system currently supports LOINC 2.76.
- **Content**: over 70,000 laboratory test and clinical observation codes.

## Taiwan Chinese mapping
- **Source**: the Ministry of Health and Welfare's EMR promotion portal — the Taiwan clinical laboratory code mapping table.
- **Value-added processing**:
    - Keyword indexing that links official English names to clinical terms commonly used in Taiwan (for example「飯前血糖」to "Glucose pre meal").
    - A Chinese alias library for specimen types and test methods.

## Reference range data
- **Source**: compiled from the published laboratory manuals of several medical centres in Taiwan (such as National Taiwan University Hospital and Veterans General Hospital).
- **Caution**: reference values vary slightly between laboratories depending on instruments and reagents. The values this system provides are for general reference only.
